## 지시

1. `$ARGUMENTS` 경로의 plan을 읽으세요. 없으면 `.workspace/plan.md`. **현재 대화에서 이미 Read한 경우 Read tool을 호출하지 말고 건너뛰세요.**
2. plan을 읽은 뒤 아래 3개를 **병렬로 즉시 실행**하세요:
   - **[병렬 A]** `Agent(subagent_type="general-purpose")`: `.claude/agents/implementation-verifier.md`를 먼저 읽고 해당 역할·체크리스트를 따르세요. plan 섹션 4(구현 원칙) + 섹션 7(검증 체크리스트) 구조·비즈니스 항목을 검사하세요. 검사 대상 파일은 plan 섹션 6의 Step 블록에서 추출하세요. 결과는 `[PASS]/[FAIL]/[SKIP]` 형식으로 반환하세요.
   - **[병렬 B]** `Agent(subagent_type="general-purpose")`: `./gradlew test`를 실행하고 실패한 테스트 목록과 원인을 요약하여 반환하세요.
   - **[병렬 C]** `Read` + `Grep`: plan 섹션 2(완료 조건) 항목별 점검
3. 3개 결과를 취합하여 아래 형식으로 보고하세요.


## 원칙
- FAIL 항목은 보고 후 사용자의 확인을 받은 뒤 수정하세요.
- plan에 정의된 항목만 검증하세요. 추가 의견은 "추가 제안" 섹션으로 분리하세요.
